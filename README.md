# Securing the Digital Marketplace – Web Application Security

## Overview
This project demonstrates hands-on application and web application security testing performed in a controlled lab environment.  
The focus is on identifying common OWASP Top 10 vulnerabilities, understanding their impact, and documenting remediation strategies to strengthen application security.

All testing was conducted ethically on intentionally vulnerable applications for educational purposes.

---

## Objectives
- Identify web application security vulnerabilities
- Validate exploitation impact in a controlled environment
- Map findings to OWASP Top 10 categories
- Propose secure coding and configuration remediations

---

## Target Applications
- Deliberately vulnerable web applications
- Simulated digital marketplace environment
- Local / lab-based deployment only

> No real-world or production applications were tested.

---

## Tools & Technologies
- OWASP Juice Shop
- DVWA (Damn Vulnerable Web Application)
- Burp Suite
- SQLMap
- Nmap
- Web browsers and manual testing techniques

---

## Vulnerabilities Assessed
- SQL Injection
- Cross-Site Scripting (XSS)
- Broken Access Control
- Insecure Input Validation
- Authentication and session handling issues

---

## Methodology (High-Level)
1. **Reconnaissance & Enumeration**  
   Identified exposed endpoints, parameters, and application behavior.

2. **Vulnerability Identification**  
   Tested inputs using manual and automated techniques to identify weaknesses.

3. **Impact Validation**  
   Verified how vulnerabilities could affect application data and users.

4. **Remediation Planning**  
   Documented secure coding practices and configuration changes aligned with OWASP guidelines.

---

## Key Learnings
- Importance of secure input validation
- Risks associated with improper access controls
- Role of web security testing in preventing data breaches
- Translating findings into actionable remediation steps

---

## Ethical Considerations
- No live user data was accessed
- No real credentials were used
- No attacks were performed outside the lab environment
